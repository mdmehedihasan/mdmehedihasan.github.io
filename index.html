LLM inference

Speculative decoding across CPU and GPU

A small draft model runs on the CPU and guesses the next few tokens. The large model on the GPU checks all of them in one pass and keeps the ones it agrees with. I measure where the time actually goes, down to each transformer block. Ongoing work toward a workshop paper.

  • CPU timing with perf counters, GPU timing with CUDA events
  • Per-block latency captured with PyTorch forward hooks
Robotics

Multi-robot SLAM on edge devices

Two Jetson Orin robots with depth cameras map a space together. A shared server merges both maps into one and tracks where each robot is relative to the other.

ORB-SLAM3Jetson OrinRealSense L515ZeroMQDocker
Details
  • Split pipeline: tracking on each robot, map building on the server
  • Map merging with duplicate map point removal
  • Live inter-robot distance and color-coded maps per robot
